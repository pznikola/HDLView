# HDLView coding instructions

For every application and tooling change, follow
[hdlview-coding-style](.agents/skills/hdlview-coding-style/SKILL.md), even when the
skill is not selected automatically. It links the coding rules, architecture
boundaries, and verification commands.
Use the smallest complete, correct implementation; avoid speculative abstractions
and unrelated cleanup. Reference checkouts are optional research material; do not
modify them to implement application behavior.

For task-specific workflows, see [the project skills](docs/AGENT_SKILLS.md).
